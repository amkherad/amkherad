## About Me

I'm a software engineer with **10+ years** of professional experience. I started programming at 15, and it has been my greatest passion ever since.

I specialize in building **scalable backend systems**, leading engineering teams, and guiding monolith-to-microservices transitions without big-bang rewrites. I care deeply about clean architecture, testability, and code that other engineers can understand and extend.

**What I focus on**

- Designing and shipping distributed, event-driven systems
- Leading teams through architecture evolution and delivery
- Writing maintainable, testable, and production-ready code
- Bridging high-level system design with low-level engineering depth
